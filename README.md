# ruT5 Slang Transfer

Учебный NLP-проект по переносу стиля. Модель переписывает фрагменты русской классической прозы на молодёжном сленге. Цель — менять лексику и тон, сохраняя события и смысл исходного текста.

[Ноутбук экспериментов](Кейс_по_NLP.ipynb) · [Демо](quick_start.ipynb) · [Готовые веса](https://github.com/mNwoK/rut5-slang-transfer/releases/tag/v1.0.0)

| Исходный текст | Ответ модели |
| --- | --- |
| Это правда. | Это база. |
| Это великолепный результат. | Это имбовый результат. |

Эти ответы получены с моделью из релиза. Те же фразы можно прогнать в демо вместе со своими примерами.

## Технологии

**Python · PyTorch · Hugging Face Transformers · SentencePiece · pandas · NumPy · Matplotlib · Jupyter**

В основе — `cointegrated/rut5-small`, русскоязычная модель на базе mT5. Для обучения используется PyTorch, для генерации — beam search. Демо работает на CPU и CUDA. [Карточка базовой модели](https://huggingface.co/cointegrated/rut5-small)

## Данные и эксперименты

Исходный датасет содержит **3 624 пары** фрагментов классики и их сленговых версий. После очистки, фильтрации по соотношению длин и ограничения в 1 536 токенов на каждую сторону осталось **3 250 пар**. Первоначальный train содержит 2 600 пар. Валидационные и тестовые выборки по 325 пар зафиксированы до аугментации.

Сравниваются четыре подхода к дообучению одной модели.

| Попытка | Что проверялось |
| --- | --- |
| Базовое дообучение | Обучение на очищенных парах. Копирование оригинала служит бейзлайном для метрик. |
| Отбор по доле правок | Оригинал и эталон сопоставляются на уровне слов через `SequenceMatcher`. В обучении остаются 382 пары с выраженными правками. |
| Взвешенная кросс-энтропия | К сильно изменённым парам возвращаются умеренно изменённые. Ошибки на заменённых и добавленных токенах получают больший вес. |
| Словарная аугментация | К 841 реальной паре добавляются 281 синтетическая. Для изменённых токенов используется вес 4. Этот вариант загружается в демо. |

Для автоматической аугментации используется словарь из 556 исходных словоформ и выражений с вариантами замены. [Словарь замен](youth_replacements.json)

## Результаты

Сохранённые результаты на **325 валидационных парах**. chrF и BLEU усреднены по парам и указаны в шкале от 0 до 1.

| Вариант | chrF ↑ | BLEU ↑ |
| --- | ---: | ---: |
| Копирование оригинала | **0.8346** | **0.7547** |
| ruT5 со словарной аугментацией | 0.6825 | 0.4685 |

Модель выучила отдельные сленговые замены, но уступила копированию по обеим метрикам. Близость эталонов к оригиналам делает копирование сильным бейзлайном. При просмотре генераций также видны ошибки согласования и случаи, где замена искажает смысл.

## Быстрый запуск

Понадобятся Python 3.11–3.13, Git, GitHub CLI и доступ к приватному репозиторию.

```sh
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git
git clone https://github.com/mNwoK/rut5-slang-transfer.git
cd rut5-slang-transfer
python -m venv .venv
```

Активируйте окружение. В PowerShell — `.\.venv\Scripts\Activate.ps1`, в Linux и macOS — `source .venv/bin/activate`.

```sh
python -m pip install -r requirements.txt
python -m jupyter lab quick_start.ipynb
```

Выполните ячейки сверху вниз. При первом запуске демо скачает готовые веса из релиза (~228 МиБ) и проверит SHA-256. Для скачивания и распаковки нужно около 510 МБ свободного места.

Для повторения обучения нужен GPU и CUDA-сборка PyTorch. Запустите ячейки [ноутбука экспериментов](Кейс_по_NLP.ipynb) по порядку. Датасет и базовая модель скачиваются во время выполнения.
