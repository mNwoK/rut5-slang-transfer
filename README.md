# ruT5: классическая проза → молодёжный сленг

Учебный проект по переносу стиля на основе `cointegrated/rut5-small`.
В репозитории сохранены эксперименты, словарь и быстрый запуск готовой модели.

## Быстрый запуск

Нужны Python **3.11–3.13**, Git, [GitHub CLI](https://cli.github.com/)
и доступ к приватному репозиторию. Один раз выполните `gh auth login`
под аккаунтом с доступом; при запросе авторизации Git выберите `Yes`.
Проверенное окружение: Python 3.13, PyTorch 2.11.0, Transformers 5.22.2.

```bash
git clone https://github.com/mNwoK/rut5-slang-transfer.git
cd rut5-slang-transfer
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux / macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Далее:

```bash
python download_model.py
python -m jupyter lab quick_start.ipynb
```

`quick_start.ipynb` загружает готовые веса и генерирует несколько ответов.
Переобучение и полный прогон валидации для этого не нужны. На CPU тоже работает;
CUDA выбирается автоматически при наличии подходящего PyTorch и GPU.

Веса находятся в **GitHub Releases**, отдельно от Git-истории. При первом запуске
скачивается только выбранный checkpoint (~250 МБ), затем проверяется SHA-256.
Для архива и распаковки нужно около 510 МБ свободного места. Изменённый или
неполный локальный checkpoint автоматически не перезаписывается; для отдельной
копии можно задать `--destination` и соответствующий путь в быстром ноутбуке.
Скрипт использует `GH_TOKEN` / `GITHUB_TOKEN`, авторизацию `gh auth login`
или сохранённые HTTPS-учётные данные Git. Секреты в файлы проекта не записываются.
Для приватного репозитория у аккаунта должен быть доступ к репозиторию и релизам.

Если GitHub CLI ещё не установлен, его можно установить отдельно:
<https://cli.github.com/>. Перед скачиванием весов выполните `gh auth login`.
Сам вход и получение доступа к приватному репозиторию выполняются владельцем аккаунта.

### GPU на Windows / Linux

На машине разработки использовался RTX 5060 Ti и PyTorch с CUDA 12.8.
Если установлен CPU-вариант PyTorch, замените его CUDA-сборкой:

```bash
python -m pip install --force-reinstall torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
```

На macOS этот шаг не нужен: быстрый ноутбук использует CPU.

## Что лежит в репозитории

| Файл | Назначение |
| --- | --- |
| `quick_start.ipynb` | Запуск готового checkpoint без обучения |
| `Кейс_по_NLP.ipynb` | Задание, анализ данных, обучение и история экспериментов |
| `youth_replacements.json` | Рабочий словарь: исходная форма → список замен |
| `youth_replacements_v1.json`, `youth_replacements_v2.json` | Предыдущие версии словаря |
| `requirements.txt` | Зафиксированные прямые зависимости |
| `model_manifest.json` | Названия, размеры и контрольные суммы checkpoint |
| `download_model.py` | Загрузка и проверка checkpoint из GitHub Releases |
| `Неделя *.html` | Предоставленные материалы занятий |

Все пять локальных checkpoint сохранены в релизе. Другой эксперимент можно скачать так:

```bash
python download_model.py --model rut5_best
python download_model.py --model rut5_v2_best
python download_model.py --model rut5_v3_weighted_best
```

По умолчанию выбран `rut5_v3_synthetic25_w4_best`: вариант с 25% синтетических
пар по числу примеров и весом 4 для изменённых токенов.

## Повторение экспериментов

Откройте `Кейс_по_NLP.ipynb`, выберите ядро установленного окружения и запускайте
ячейки последовательно. Зависимости устанавливаются через `requirements.txt`;
дополнительные `pip install` внутри ноутбука не нужны.

Данные загружаются из исходной Google Drive-таблицы:
<https://drive.google.com/file/d/1wn6jpF5-FeaZIo2oqSspSvbfjIiVa8F7/view>.
CSV не включён в репозиторий; для первого скачивания нужен интернет.
Базовая модель при обучении загружается с Hugging Face.

Обучение рассчитано на GPU. В исследовательском ноутбуке предусмотрена проверка
CUDA; на CPU используйте `quick_start.ipynb` для готовой модели.
Полное обучение всех вариантов и генерация сотен длинных текстов занимают
значительно больше времени, чем быстрый запуск. Перезапуск обучающих ячеек
повторно обучает модели и может перезаписать соответствующие локальные checkpoint.

В ноутбуке сохранены исторические выводы, включая прерванный последний запуск.
Они документируют ход работы; не все выводы соответствуют одному чистому запуску.
В исходном коде исправлены синтаксическая ошибка, границы первоначальной фильтрации
и инициализация кеша для воспроизводимого последовательного запуска.
Гиперпараметры и архитектура опубликованного checkpoint не изменены.

## Метрики и ограничения

В задании используются обычная кросс-энтропия и предоставленные реализации
chrF/BLEU. Валидация используется для выбора модели; `test_df` выделен отдельно.
Генерация выполняется один раз на checkpoint, затем метрики считаются по кешу.

Это экспериментальная модель. Она может копировать оригинал, ошибаться
в согласовании и менять смысл. Словарь содержит кандидаты замен и сам по себе
не является гарантией их применения. Автоматическая синтетика может содержать
ошибочные цели. При быстрой проверке возможны ответы вроде «Это правда.» →
«Это база.», но результат зависит от текста и среды вычислений.

Проект не использует API языковых моделей для генерации при запуске.
Сведения об исходной модели и материалах: [THIRD_PARTY.md](THIRD_PARTY.md).
