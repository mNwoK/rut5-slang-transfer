# Источники

- Базовая модель: [cointegrated/rut5-small](https://huggingface.co/cointegrated/rut5-small).
  В карточке исходной модели указана лицензия MIT. Опубликованные checkpoint
  получены дообучением этой модели. Архитектура и веса происходят из цепочки
  `google/mt5-small` → `alenusch/mt5small-ruparaphraser` → `cointegrated/rut5-small`.
  Сведения об авторах и условиях upstream-компонентов находятся в их карточках.
- [google/mt5-small](https://huggingface.co/google/mt5-small).
- [alenusch/mt5small-ruparaphraser](https://huggingface.co/alenusch/mt5small-ruparaphraser).
- Датасет и задание предоставлены в рамках учебного кейса; ссылка на исходные
  данные сохранена в README и исследовательском ноутбуке. CSV не распространяется
  вместе с Git-репозиторием.
- HTML-презентации — предоставленные пользователем материалы занятий.
- Словарь и синтетические пары — учебная аугментация; они не являются
  нормативным словарём русского языка и не гарантируют сохранение смысла.

Этот файл фиксирует происхождение материалов и не меняет их исходные лицензии.
